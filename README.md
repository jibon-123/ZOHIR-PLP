# কার্ড স্টুডিও

ফটো কার্ড / কোট কার্ড / নিউজ কার্ড মেকার। একটাই ফাইল: `index.html` (কোনো সার্ভার বা বিল্ড লাগে না)।

## GitHub Pages-এ চালু করার নিয়ম
1. নতুন রিপো বানান, `index.html` আপলোড করুন।
2. Settings → Pages → Branch: `main` / root → Save।
3. কিছুক্ষণ পর `https://ইউজারনেম.github.io/রিপো-নাম/` এ সাইট চালু হবে।

## কাস্টমাইজ (index.html এর শুরুতে `CFG`)
- `price`, `payNumber`, `contactLink` : প্রো প্ল্যানের দাম, বিকাশ/নগদ নম্বর, হোয়াটসঅ্যাপ লিংক
- `proCodes` : পেমেন্ট পাওয়ার পর ইউজারকে যে কোড দেবেন

## নিজের ছবির টেমপ্লেট যোগ করা
1. টেমপ্লেটের ছবি (১০৮০×১০৮০ PNG/JPG, লেখার জায়গা ফাঁকা) `templates/` ফোল্ডারে রাখুন।
2. `CFG.imageTemplates` এ যোগ করুন:
```js
{id:'my1',name:'আমার ডিজাইন',pro:false,src:'templates/my1.png',
 box:{x:90,y:300,w:900,h:500},color:'#111',accent:'#c00',align:'center',size:80}
```
`box` = লেখা বসার জায়গা। `pro:true` দিলে প্রো ইউজাররা পাবেন।

## মূল লেখায় রঙিন শব্দ
শব্দটি `*তারকা*` চিহ্নের ভেতরে লিখুন।

## সীমাবদ্ধতা
প্রো কোড যাচাই ব্রাউজারেই হয়, তাই কেউ কোড দেখে ফেললে বাইপাস করতে পারে। বেশি ইউজার হলে Firebase/সার্ভার দিয়ে কোড যাচাই করুন।
